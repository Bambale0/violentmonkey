# Legacy Userscript Experiments

> **Archived/legacy code. Not an active portfolio project.**

This repository contained early browser userscript experiments and is no longer maintained.

Two old scripts were removed from the current branch because they contained a hardcoded third-party API credential. Credentials must never be embedded in browser scripts or committed to source control.

## Security note

The exposed credential must be treated as compromised and rotated at the provider. Removing a file from the current branch does not erase old Git history by itself.

## Portfolio note

This repository is kept only as legacy history. The production projects on this GitHub profile are the relevant examples of current engineering work.
